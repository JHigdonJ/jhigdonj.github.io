# GIS Portfolio

This repository contains the source files for my GIS portfolio website.

## Structure

- `index.html` — home page
- `assets/style.css` — site styling
- `projects/` — individual project pages
- `assets/` — images and other site assets
- `resume.pdf` — optional résumé

## GitHub Pages

Create a repository named `<your-github-username>.github.io`, upload these files to the `main` branch, then go to:

**Settings → Pages → Build and deployment → Source → Deploy from a branch → main → /(root)**

GitHub will publish the site at `https://<your-github-username>.github.io/`.

Replace all placeholder text, links, images, and skills before sharing the site professionally.
